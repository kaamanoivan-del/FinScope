# FinScope

FinScope es una aplicación de análisis financiero desarrollada con
Python y Streamlit.

Integra análisis fundamental, valoración, históricos de mercado,
riesgo, estadística, Monte Carlo, escenarios, análisis cuantitativo,
cartera personal y herramientas de Machine Learning.

## Instalación

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

## Ejecución

    streamlit run app.py

## Datos

Los datos financieros se obtienen principalmente mediante
yfinance/Yahoo Finance. Su disponibilidad y actualización dependen
de la fuente original.

## Aviso

FinScope es una herramienta de análisis e información financiera.
Las estimaciones, simulaciones y modelos no garantizan resultados
futuros y no constituyen asesoramiento financiero.
